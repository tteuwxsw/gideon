# 🤖 Gideon

Assistente pessoal com IA inspirada na Gideon do The Flash.

## 🚀 Instalação Rápida

**Duas formas:**

### 1. Linha de comando (Python)
```bash
python -m gideon.wake
```

### 2. Executável (.exe)
```
dist\GideonWake.exe
```

📖 [Guia completo de instalação](INSTALAR.md)

---

## ✨ Recursos

- 🎙️ Controle por voz
- 🧠 IA Gemini integrada
- 🖥️ Automação desktop
- 📱 Interface web local
- 🔒 Privacidade total (roda offline)

---

## 📦 Estrutura

```
gideon/
├── cerebro.py       # Motor de IA
├── voz/            # Síntese e reconhecimento
├── servidor.py     # API local
└── wake.py         # Ponto de entrada
```

---

## ⚙️ Configuração

1. Copie `.env.example` para `.env`
2. Adicione sua chave Gemini:
   ```
   GEMINI_API_KEY=sua_chave_aqui
   ```
3. Execute
